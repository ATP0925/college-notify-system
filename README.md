# College Notify System

A Java mini project for a college notice and submission system.

## Features
- Student login and registration
- Admin / Faculty role support
- Notice publishing
- Student submission of links and messages
- Status update for submissions
- Bootstrap-inspired UI with Thymeleaf

## Tech Stack
- Java 17
- Spring Boot 3.3
- Spring Data JPA
- H2 in-memory database
- Thymeleaf

## Run locally
```bash
git clone https://github.com/ATP0925/college-notify-system.git
cd college-notify-system
./mvnw spring-boot:run
```

Then open:
- http://localhost:8080/login
